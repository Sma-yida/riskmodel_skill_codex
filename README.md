# 风控建模 Skill

将本地风控二分类建模后台封装成可通过自然语言使用的 Skill，覆盖数据分析、清洗切分、特征筛选、训练与评估。支持 LightGBM、AutoGluon 和 LR 评分卡。

**`risk-modeling/` 是唯一的 Skill 交付本体。** 本项目其他目录用于开发、文档、验收、网页和发布管理，不装进 Skill ZIP。用户的业务数据、运行环境与模型产物另放独立工作目录。

## 开始使用

1. 解压 ZIP，将完整的 `risk-modeling` 文件夹放到 Codex 的用户级 Skill 目录：macOS/Linux 为 `~/.agents/skills/risk-modeling/`，Windows 为 `%USERPROFILE%\.agents\skills\risk-modeling\`。确保该目录下直接有 `SKILL.md`，不要多套一层同名目录。同名旧版先移出 Skill 扫描目录，避免加载混淆。安装位置依据 [Codex 官方说明](https://learn.chatgpt.com/docs/build-skills)。
2. 在 Codex 打开用于本次建模的项目文件夹，新建对话并选择或输入 `$risk-modeling`。可先让助手核对加载路径及版本 `1.0.0-rc.2`；若未发现，重启 Codex 后再试。
3. 首次可以说：**“使用 $risk-modeling，在当前目录准备一个建模项目。”** 助手先检查环境、目录、数据与进度，再给具体准备清单；确认后完成准备，并告诉你数据应放在哪里。已有环境或工作目录可直接指定，优先使用指定值。
4. 按指定格式放好数据后说：**“数据已放好，使用默认参数进行数据质量分析。”** 核对标准需求清单，再确认执行；之后按报告中的下一环节推荐问继续。点击推荐问只是提出需求，确认参数清单后才会执行。

数据格式查询：主数据为 `data.csv`、`data.parquet` 或 `data.feather`，同名数据只留一种；外部验证数据可使用 `oot_*`。基础列为 `id/date/label/channel`，标签须符合后台固定的 `1=坏样本、0=好样本`；本期不提供自动列映射或反向标签转换。正常交互无需重复说明这些约定。

**换电脑使用**：复制同一 ZIP，按上面步骤安装，在目标电脑选择并验证已有建模环境，或确认后新建环境。ZIP 不含 Python/Java 环境、业务数据和模型；不要把 Mac 虚拟环境直接复制到 Windows。Windows 已有 conda 环境时可说：“使用 $risk-modeling，建模环境用 bx，工作目录用 D:\风控项目A，先检查并给我准备方案。”迁移已有项目时保留完整工作目录，并重新核验环境、绝对路径和已有结果，不能只复制 `data/` 就视为进度已恢复。

**在其他助手中使用**：宿主需要支持读取 `SKILL.md`、访问本地文件和运行 Python/终端命令；按该宿主的规则安装完整文件夹。仅把 ZIP 上传到普通聊天窗口不等于安装。选项按钮取决于宿主能力，不支持时回退到编号选项；其他宿主的完整执行仍需实测。

首次项目准备时展示目录、环境与数据位置；后续标准清单使用“环节 → 中文含义（参数名）：值 [来源]”，切换或异常时才重新显示准备项。模板值标“默认”，本次指定标“用户修改”，历史非默认值标“保留当前”，自动变化标“联动”；用户明确要求默认时，只恢复所选环节生效分支并展示差异。选择推荐问或接受纠正均不授权执行，必须再确认标准清单；执行完成按“结果及报告 → 环节指引 → 推荐问”输出。确认后复用预检时的同一份参数变更，通过脚本写入并读回核对；未改项保留，发现差异先停下。该复核由助手遵循规则完成，没有新增确认凭证或自动绑定方案的系统。

工作目录中的 `config/project.json` 保存已验证的环境，属于项目运行配置，不是聊天会话配置。五份环节配置保存参数，进度使用原有任务日志。工作目录通过用户指定或当前项目定位，调用时显式传入；不在配置中重复保存根路径。旧标签记录兼容保留，正常交互不追问、不展示、不将其作为可调参数；仅发现与固定数据约定冲突时提示。重新对话时读取项目及执行记录并核查当前文件；不把保存的信息当作长期执行授权。旧项目无需重建，首次核对后可绑定环境。不同任务使用不同目录；同一父目录另开任务时推荐未占用的 `riskmodel_work_2/` 等目录，聊天窗口本身不提供文件隔离。Skill/脚本与可用环境可以共用，正常建模不改程序或升级共用环境；项目创建后的环境诊断通过 `--log-dir` 保存在该目录的 `logs/`。

控制脚本需要 Python 3.8+，建模环境使用 CPython 3.9、Java 与固定依赖；详见 [环境指南](references/setup.md) 和 [需求澄清与选项交互](references/first-use.md)。需要回答时优先提供宿主支持的可点击选项和自由输入；不支持时使用编号选项。用户数据、配置、模型产物及日志放在独立工作目录，不放入 Skill 安装目录。

当前不支持自动多版本试验管理、训练断点续训或通用新数据独立评分入口。寻优沿用原后台，不能保证严格绝对 KS gap 或只按 test 最终选模；LightGBM 新评估 Excel 会附带复现拟合，评分卡第五步复用训练报告。程序成功不等于业务条件满足。
